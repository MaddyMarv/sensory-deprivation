Challenge mod that blinds your screen and/or mutes in game audio. Includes a keybound LIDAR scanner to pulse and map terrain, optional explosion flashes, and a speedrun timer.

Please check the required files for options to make it slightly easier!

Thanks to the Lidar mod for having an assistance option when blind! I took all of the lidar code from there with permission. :)

[b]Options:[/b]

[b]Challenge Settings[/b]
- Blindness Challenge (Mute Sight)
- Deaf Challenge (Mute Sound)
- Explosion Flashes (SEIZURE WARNING)
- Flash Trigger Range (Meters)
- Enable Personal Speedrun Timer

[b]Scanner Settings[/b]
- Enable LIDAR Scanner
- FOV Scan (Hotkey)
- 360 Radial Scan (Hotkey)
- Scanner Max Range (Meters)
- Auto-Pulse Scanner
- Auto-Pulse Interval (Seconds)
